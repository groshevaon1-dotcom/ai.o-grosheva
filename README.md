# Grosheva AI Lab — сайт-портфолио

Одностраничный лендинг: автоматизация бизнеса на ИИ (бизнес-аналитик и архитектор).

- Статический сайт (HTML/CSS/JS), без сборки.
- Домен: https://ai.o-grosheva.ru
- Дизайн-система Terra Nova (токены `css/tokens.css`, шрифты Onest/Literata).

## Структура
- `index.html` — страница
- `css/` — токены и стили
- `js/main.js` — ссылки в мессенджеры
- `assets/` — шрифты, изображения, favicon, OG-превью

## Деплой
Залить содержимое корня (`index.html`, `css`, `js`, `assets`) в папку сайта на хостинге.
